# Нанкењике · nankeńike

Конланг, который мы строим вместе со зрителями на стримах канала
[Azoy Sheyn](https://youtube.com/@azoysheyn). Название — «то, на чём мы говорим»:
*nan-* (делает существительное) + *кењ* «мы» + *и-кэ* «говорить».

Сначала было письмо — рукописные «каракули» без языка за ними, — а язык делается под него.
Строй полисинтетический, как в чукотском: «он их догнал и ест» — одно слово.

**Стабильная версия языка — [`nankenike.md`](nankenike.md).** Там только принятые решения,
с датой; отменённое не стирается, а уходит в раздел «История».
